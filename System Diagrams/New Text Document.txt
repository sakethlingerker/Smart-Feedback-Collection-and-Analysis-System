# System Architecture

## Overview

The Smart Feedback System follows a **three-tier architecture** with clear separation between presentation, business logic, and data layers.

```mermaid
flowchart LR
    subgraph Frontend
        UI[Web Interface<br/>Vanilla JS]
        Dashboard[Admin Dashboard<br/>Chart.js]
    end
  
    subgraph Backend
        API[Flask REST API<br/>Python]
        Auth[JWT Authentication]
        SA[Sentiment Analysis Engine]
    end
  
    subgraph Data
        DB[(SQLite Database)]
    end
  
    subgraph External
        HF[HuggingFace API]
        SMTP[Email Service]
    end
  
    UI --> API
    Dashboard --> API
    API --> Auth
    API --> SA
    API --> DB
    SA --> HF
    API --> SMTP
```
